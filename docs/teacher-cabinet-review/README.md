# O‘qituvchi kabineti: kod va davom ettirish ko‘rsatmasi

Bu ko‘rib chiqish arxivi. Undagi patchlar va SQL takliflari ishga ulanmagan. Ularni birgalikda yoki ishlab turgan bazaga qo‘llamang. Hozirgi `main`da faol kod yo‘liga kiritilgan yagona yangi qism — [Ustozga kirish sahifasi](../../apps/mini-app/teacher-entrance/); u ham hali joylashtirilmagan. Bu arxiv Mini, Clerk, Telegram yoki hisobni o‘chirish oqimlarini o‘zgartirmaydi.

Arxivdagi sxema, SQL va kod parchalari o‘zining ko‘rsatilgan commitiga tegishli. Yangi kabinet uchun identifikator nomi **UniverAcademy ID**. Joriy API maydoni va eski mijozlar bilan moslik [ID hujjati](../univeracademy-id.md)da.

## Nazoratchi uchun ish tartibi

Avval [fayllar ro‘yxati va holati](FAYLLAR.md)ni o‘qing. Har bir papkadagi patchlarni faqat bitta yo‘nalish sifatida, alohida ish nusxasida ko‘rib chiqing. Amaldagi `main` bilan taqqoslang: dastlabki ishlanmalar `3dbb714f2f758c7dbe03548a71c161718cf9cb53` bazasiga tayangan. Ko‘rsatilgan tartib texnik bog‘liqlikni bildiradi, deploy yoki ruxsat berish ko‘rsatmasi emas. Ko‘p asosiy patchlar birgalikda statik tekshirilgan; hammasi birgalikda qo‘llanmagan. Bitta o‘zgarishning bir necha varianti bor.

## Qaysi variantni olish kerak?

- **Ustoz:** `browser/ustoz-existing-clerk-email-entrance.patch.txt` parolga asoslangan oldingi patchni almashtiradi. U joriy manbada allaqachon bor; yana ustidan qo‘llamang.
- **Brauzer:** `browser/candidate`, `teacher-bootstrap/candidate`, `browser-pilot/candidate`, `browser-pilot-postgres/candidate`, keyin `browser/read-only-activation-entry`. Telegramdan sessiyani avtomatik ko‘chirish tajribasi (`browser-continuation`) bu zanjirga kirmaydi.
- **Bitta guruh, nashr qilingan test:** `one-group-pilot/one-group-pilot-assignment` → `ordinary-presentation/ordinary-presentation` → `ordinary-presentation/pilot/pilot-ordinary-numbers` → `one-group-pilot/student-projection/pilot-student-projection-hardened` → `one-group-pilot/staff-projection/pilot-staff-scope`. Qoralama yo‘llari aralashmagan `one-group-published-worker-surface`ni tanlang; u yo‘llarni o‘zi yoqmaydi.
- **O‘quvchini qo‘shish:** `single-group-pilot-roster` ichida `candidate` → `locked-attachment-rows` → `opaque-preview-binding` → `attachment-receipt-minimization`. Guruh nomi, dastlabki guruh va ID qidiruvi alohida ko‘rib chiqiladi.
- **Qoralama (keyin):** `teacher-create-draft/candidate` → `locked-rows-hardened` → `prepared-clerk-runner-deletion-gate` va alohida `dedicated-writer-commit-proof`. Runner brauzer Postgres patchidagi qulf yordamchisiga bog‘liq; brauzer roli yoki parolini olmasligi kerak. Oldingi `locked-rows` va `prepared-clerk-runner` o‘rniga yuqoridagi variantlar. Qoralamani bekor qilish patchi faqat niyatni tekshiradi; bu bekor qilishni hali bajarmaydi.
- **Birlashtirilgan patchlar:** `consolidated-cabinet-review` va uning tarkibiy qismlari birga qo‘llanmaydi. `combined-candidate` tarixiy taqqoslash uchun. Access va nashr qilingan test qismlari ayrim umumiy server fayllariga tegadi; ularni birga qo‘llash qayta tekshirilishi shart.

`.patch.txt` va `.review.sql.txt` fayllari tekshiruv materiali, faol kod yoki migratsiya emas. Jonli baza, ruxsat, DNS yoki bot sozlamasi uchun bu fayllardan avtomatik buyruq chiqarmang.
