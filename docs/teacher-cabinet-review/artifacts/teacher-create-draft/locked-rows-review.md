Apply candidate.patch before locked-rows.patch against pinned 3dbb714f2f758c7dbe03548a71c161718cf9cb53. Adds a typed adapter only. It uses canonical LockedTransaction + own/query/integer, StaffAccessRows.load(...,"clerk"), ordered actor→group locks, and existing staff receipt/audit insert shape. It takes a server-approved pilot subject and group, and insists on a current Teacher staff record (no Admin/Owner) with exactly that explicit nonrevoked active group, no global group/subject scope, and current subject approval. New operation additionally requires valid explicit ordinary grading, actual title and duration. Source compatibility: copied schema-catalog and extended catalog show required demos and test_versions columns, demo FK, matching draft wire checks, reciprocal initially deferred receipt/audit FKs, immutable history and FORCE RLS.

For an authorized operation the actor/group-qualified keyed receipt is checked before allocation. New writes are one demo, one Version v1/rev1 draft (SQL NULL snapshot, no questions), one receipt and its paired audit on the same caller transaction. No membership, exam, publishing, ownership or visibility change. Replay reauthorizes, matches request/audit and original version/demo/subject, returns only original IDs, and cannot overwrite a new revision or return a stale draft DTO. Unexpected rows or a receipt insert collision throw so the caller must roll back the whole transaction; recovery for commit-unknown is the same key and input with fresh authorization, never a new create. Existing edit/publish and actor-staff assembly are untouched.

No mount or HTTP contract. Use only a separately reviewed dedicated writer and verify actual lock/ACL/policy scope, including receipt reads, paired audit write, and delete lifecycle for first_draft_create. No authority is asserted by this patch. Preserve existing audit even while the erasure compatibility prerequisite is unresolved; never wire an unaudited workaround.
