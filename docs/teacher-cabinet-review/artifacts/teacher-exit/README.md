# Teacher account exit: own scope release, no successor required

Based on canonical 3dbb714f2f758c7dbe03548a71c161718cf9cb53 and the owner's corrected exit rule. This candidate adds application logic only. No DDL, SQL, actual group release, handoff, deletion, grant, fixture, or deployment.

The release operation independently requires the current authenticated Teacher and complete exact grant snapshot under one trusted person/scope transaction. A client-provided explicit group ID set is compare-and-set consent, not authorization. It can revoke only this actor's currently explicit group-scope rows, checks exact affected IDs and rechecks current authorization and empty scope before returning. An already empty consent/snapshot is a no-op; stale scope conflicts and requires a refresh rather than presuming an earlier uncertain request succeeded. Higher/global authority stays outside this narrow Teacher operation. No successor, group, roster, membership, student, attempt, role or history change is part of the command.

A separate advisory readiness check intentionally requires no successor. It requires that the deletion coordinator prove no current own grants, no identity-linked technical history and all other existing safeguards clear. No caller claim can supply those facts. It does not modify the deletion coordinator or override its controls. The pinned SQL proposal account-deletion-rebuild.review.sql currently rejects any staff group-scope row (including revoked), staff actor/target history and multiple other staff references; releasing explicit scope alone cannot make the existing deployed deletion behavior claim ready. A separately approved audited persistence/anonymization mechanism must reconcile those references without retaining raw identifiers or affecting any group/student history. Optional handoff remains disabled until an approved actual recipient/current authority and narrow transfer spec exist; never grant another role or move participants in this exit path.

Validation is static only: reverse/forward strict patch apply, exact bytes and stripped TypeScript syntax. No runtime calls, role changes or synthetic data.
