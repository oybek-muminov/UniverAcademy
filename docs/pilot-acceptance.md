# Birinchi fizika guruh testi

Holat: reja. Quyidagi amallar bajarildi deb qayd etilmagan.

## Mahsulot doirasi

Bitta haqiqiy fizika testi, 10–30 kishilik birinchi guruh, Telegram Mini App. Birinchi testni admin tayyorlaydi. O‘quvchi ro‘yxatdan o‘tadi; o‘qituvchi yoki admin tegishli vakolat bilan guruhga qo‘shadi. Fizika muvaffaqiyatidan keyin matematika shu mexanizmda ochiladi.

Haqiqiy savollar/kalit, duration, roster, kun va admission oynasi mavjud materiallardan tekshiriladi. Ularni namunaviy ma’lumot bilan almashtirib pilot tayyor deyilmaydi.

Oddiy natija asosiy; statistik bonusning birinchi pilotdagi navbati alohida belgilanadi. Bonusning tasdiqlangan qoidasi bekor qilinmaydi. Rasch, to‘lov, video, diagnostika, avtomatik jazolash va jonli tahlil pilot sharti emas.

## Tekshiriladigan oqim

1. Telegram kirish, ism-familiya, ruxsatli testlar.
2. Guruh/individual admission va boshlash tasdig‘i.
3. Bittadan savol, erkin navigatsiya, urinish davomida barqaror aralashtirish.
4. Server timeri, CAS javob saqlash, aloqa uzilganda reconcile, generation/recovery ajralishi.
5. Yakunlash tasdig‘i va oddiy earned/max/percentage natijasi; bonusni kutmaydi.
6. O‘z natijasi/history va staffning ruxsatli monitoringi/Excel.
7. Batafsil review faqat tegishli admission/started-attempt/approval gate bilan.
8. Ruxsatli recovery yangi bo‘sh urinish va to‘liq vaqt; eski tarix saqlanadi.

## Xavfsizlik va izchillik

Student/staff proof ajratilishi; initData/refresh replay; IDOR va boshqa guruh ma’lumotini ko‘rmaslik; revoked scope; parallel save/submit/force/deadline; nol yo‘qolgan tasdiqlangan javob; nol takror natija; keyning erta oshkor bo‘lmasligi.

Bonus qo‘shilsa: wrong ichida unanswered, N1, N0 no snapshot, current valid self-submitted cohort, no-show/expired/forced/cancelled exclusion; all-started va himoyalangan Asia/Tashkent admission/recovery gate; Teacher/Owner huquqi va Admin POST/replay rad etilishi; same/different key va parallel clickda yagona atomik snapshot; ordinary o‘zgarmasligi; successor attribution.

## Dalil

Har testda muhit, commit, API versiyasi/xeshi, konfiguratsiya, natija va cheklov yoziladi. Schema/formula tekshiruvi runtime yoki haqiqiy pilot o‘rnini bosmaydi. Birinchi guruh hajmi va taklif sifatida uning ikki baravarida sinov; 10 ming bir vaqtdagi foydalanuvchini qabul qilishdan oldin alohida katta yuklama dalili.

p95/SLO, maksimal ruxsatli xatolar va tiklash talablari kelishilgan qiymatlar bilan qayd etiladi; tarixiy takliflar tayyor test natijasi deb ko‘rsatilmaydi.
