# O‘quvchi Mini App

Mas’ul: Bot/Mini App agenti.

Oqim: Telegram launch → custom student session → profil → ruxsatli test → start/timer/save/reconcile → submit → own result/history → ruxsatli review.

Kirish, ruxsat, vaqt va baholashning authoritative qarori Backendga tegishli. Client StaffJWTni o‘quvchi proofi sifatida ishlatmaydi. Save CAS va generation qoidalariga mos; refresh va submit retrysi kontrakt bo‘yicha bajariladi.

API 0.2.7 draft; o‘zgarmagan UI/mocks tayyorlanishi mumkin, yangi integratsiya Backend review qilgan aniq versiyaga bog‘lanadi. Ushbu papkada hozir executable kod, package manifesti yoki dependency lockfile yo‘q.
