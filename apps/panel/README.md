# Boshqaruv paneli

Mas’ul: Panel agenti.

Ega, Admin va O‘qituvchi uchun brauzer interfeysi. Staff Google yoki email/parol orqali Auth; providerning haqiqiy sozlamasi alohida tekshiriladi.

Asosiy ishlar: onboarding va ruxsatli guruh/roster, tasdiqlangan fan kontenti, test/version/assignment, monitoring, natija va Excel; tegishli huquq bilan review/recovery; optional statistik bonus UI.

O‘qituvchi tasdiqlangan fan kontentini boshqarishi mumkin, boshqa guruh o‘quvchi/natijalariga avtomatik kira olmaydi. Bonus activation Teacher own scope/Owner huquqi bo‘yicha, Admin activation/replay qilmaydi. Server current role va scopega qayta tekshiradi.

UI taxminiy endpoint yoki yangi mahsulot qoidasi kiritmaydi. Hozir faqat papka vazifasi yozilgan.
