# UniverAcademy

UniverAcademy — ko‘p fanli mustaqil ta’lim platformasi. Birinchi bosqich: Telegram Mini App orqali admin tayyorlagan bitta fizika guruh testi, so‘ng matematika.

## Repozitoriylar

- Loyiha fayllari: https://github.com/oybek-muminov/UniverAcademy
- Yordamchi manbalar, tadqiqot va tajribalar: https://github.com/oybek-muminov/lab_univeracademy

Laboratoriya materialining mavjudligi uni loyiha uchun qabul qilingan yoki ishlayotgan kodga aylantirmaydi.

## Boshlang‘ich holat

Bu tuzilma hujjatlar va ish chegaralarini tayyorlaydi. Ishlovchi API, ilovalar, migration, deploy yoki muvaffaqiyatli pilotni anglatmaydi.

API 0.2.7-statistical-bonus-review.1 — PROVISIONAL / NOT ACCEPTED. Backend API egasi; yangi kontrakt xeshi bo‘yicha consumer review alohida olinadi.

## Qismlar

- `apps/landing/`: mavjud tashrif sahifasi.
- `apps/mini-app/`: o‘quvchi interfeysi.
- `apps/panel/`: Ega, Admin va O‘qituvchi kabinetlari.
- `supabase/functions/univeracademy-api/`: yagona API va modullarga ajratilgan backend.
- `supabase/migrations/`: Backend ko‘rib chiqadigan baza o‘zgarishlari.
- `packages/api-client/`: kelishilgan OpenAPI asosidagi mijoz.
- `tests/backend/`, `tests/e2e/`, `tests/load/`: tegishli tekshiruvlar.
- `docs/`: arxitektura, mas’uliyat, manba holati va qabul mezonlari.
