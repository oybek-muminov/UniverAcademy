# Yuklama va tiklanish sinovlari

Mas’ul: QA; Backend infratuzilma cheklovlari va o‘lchovlarini beradi.

Bosqichlar: avval 10–30 kishilik fizika piloti uchun haqiqiy oqim; keyin platforma bo‘yicha 10 minggacha bir vaqtdagi test maqsadi uchun alohida muhitda yuklama dalili.

Ssenariylar: start cho‘qqisi, real javob almashishi/CAS, submit cho‘qqisi, uzoq ishlash, uzilish va server almashishi, notifications/reportlar bilan birga ishlash. Ro‘yxat/tarix hajmi sun’iy ma’lumot bilan alohida sinovdan o‘tadi; 10 million profil 10 million virtual user deb olinmaydi.

Har natijada commit/API xeshi, muhit quvvati, guruhlar va eng katta cohort, vaqt, so‘rov taqsimoti, p95/p99/error rate, DB kutishlari/ulanishlar/IO va yo‘qolgan tasdiqlangan javoblar qayd etiladi. Maqbul limitlar kelishiladi; misol raqamlari SLO deb qabul qilinmaydi.

Haqiqiy bazaga yoki providerga yuk yuborish ushbu README bilan ruxsat etilmaydi. Hozir benchmark o‘tkazilmagan.
