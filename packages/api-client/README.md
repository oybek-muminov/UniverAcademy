# API mijoz paketi

Mas’ul: Backend; Bot/Mini App va Panel iste’molchilar.

Backend kelishgan OpenAPI versiyasi va aniq xeshi asosida generated tip/mijoz yaratiladi. Hozirgi 0.2.7 PROVISIONAL / NOT ACCEPTED bo‘lgani uchun bu bosqichda generated kod yoki generator/dependency tanlovi yaratilmagan.

Qo‘lda parallel endpoint/tip nusxalari yuritilmaydi. Client generation biznes qoidalari, server arifmetikasi yoki authorizationni tekshirganlik dalili emas. Authentication proof turlari va amaldagi error/retry semantikasi saqlanadi.
